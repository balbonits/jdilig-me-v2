A showcase of web component-based applications built entirely with vanilla JavaScript. Six interactive applications demonstrate the power of native browser APIs without any framework dependencies.

## Key Highlights

- **Zero framework overhead** with native Web Components and Shadow DOM
- **True component encapsulation** without build tools or transpilation
- **Under 50KB total** bundle size for all six applications combined
- **Progressive enhancement** with graceful degradation

## Applications

The suite includes a drawing app, todo list, mind mapping tool, markdown editor, shopping cart, and more — each built as a self-contained web component with local storage persistence and responsive design.
